# 🩸 Blood Donor Radar

A Java-based blood donor management system developed using **Advanced Java, JDBC, and MySQL**. The project demonstrates database connectivity and CRUD operations for managing blood donors and related donation information.

## 📌 Project Overview

Blood Donor Radar is designed to organize blood donor information and related records in a structured database. It demonstrates how a Java application can connect to a relational database and perform operations on donor details, blood banks, donation camps, and donation records.

## 🎯 Objectives

* Store and manage blood donor information.
* Maintain blood bank records.
* Organize donation camp information.
* Record blood donation activities.
* Implement CRUD operations using JDBC.
* Demonstrate relational database design and Java–database connectivity.

## 🛠️ Technologies Used

* **Programming Language:** Java
* **Database:** MySQL / MariaDB
* **Database Connectivity:** JDBC
* **SQL Operations:** INSERT, SELECT, UPDATE, DELETE
* **Development Environment:** NetBeans IDE
* **Database Access:** PreparedStatement and JDBC connection APIs

## 🗄️ Database Design

The project uses related database tables to organize information:

* `donor` — stores donor information.
* `blood_bank` — stores blood bank details.
* `donation_camp` — stores donation camp information.
* `donation_record` — stores donation records and relationships between donors and camps.

Primary keys and foreign keys help maintain relationships between the tables.

## ⚙️ Features

* Database connectivity through JDBC.
* Insert new donor records.
* Retrieve and display donor records.
* Update existing donor details.
* Delete donor records.
* Manage blood bank records.
* Manage donation camp records.
* Store donation records.
* Handle database errors and invalid user input.

## 🚀 How to Run

1. Install the Java Development Kit (JDK).
2. Install MySQL or MariaDB.
3. Create the project database and tables using the SQL scripts included in the repository.
4. Add the MySQL JDBC driver to the project.
5. Update the database URL, username, and password in the database connection configuration.
6. Open the project in NetBeans or a compatible Java IDE.
7. Build and run the application.
